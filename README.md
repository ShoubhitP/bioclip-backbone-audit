# BioCLIP Backbone Audit

A controlled empirical study of how BioCLIP 2's domain-specialized training changes the transfer behavior of its shared visual backbone relative to its LAION-2B ViT-L/14 initialization.

## Research Question

How does biological specialization change low-data transfer performance on biological and non-biological visual recognition tasks?

## Models

- LAION-2B CLIP ViT-L/14
- BioCLIP 2 ViT-L/14

## Datasets

- Oxford Flowers102 — biological fine-grained recognition
- Describable Textures Dataset (DTD) — non-biological control
